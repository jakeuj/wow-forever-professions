02 / ROUTE

每一段做什麼。

次數是照升級機率估的期望值：變黃以後做一次不一定加一點；「多備」是 9 成情況下夠用、要多準備的次數。

    全是訓練師配方，不用買設計圖。

  2. 35 級學工匠級鍛造

    沒學會會卡在 225。

  3. 225→258平衡石、秘銀細劍

    平衡石幾乎不花錢；細劍要寶石。

  4. 258→300瑟銀長靴、巨劍、輻光護腿

    瑟銀錠為主；長靴與輻光護腿的設計圖部落各只剩 1 張，最後一段要火焰之心。

05 / BEFORE YOU START

開始前先看。

35 級才學得到工匠級

  • 封測期攻略：工匠級鍛造需要鍛造 200 與角色 35 級，未滿 35 級會卡在 225；以遊戲內為準。
  • 階段 2 的材料可以等快到 35 級再買，價格到時再看。

貨不夠時

  • 路線已經避開買不到的材料；還標「不夠」的，是換配方反而更貴，分幾天買。
  • 部落出現瑟銀護腿設計圖就買：可取代輻光護腿，不用火焰之心。
  • 有採礦的話，瑟銀礦石自己熔錠也行。

沒算進去的

  • 訓練師學費。
  • 大量收購會越買越貴：這裡用最低一口價乘數量，瑟銀錠這種要買上千個的會低估。無限副本手冊用全部掛單的平均價，比較接近大量買的成本。
  • 部落拍賣場現在沒貨的設計圖，見設計圖表的「看到就買」。

06 / IN GAME

在遊戲裡自己排路線。

這頁的路線是站主掃描當下算出來的快照。想照自己身上的材料和最新行情重算，可以用無限副本手冊搭配拍賣小幫手，在遊戲裡直接排出最省錢的練級路線。

先裝兩個插件

  • 無限副本手冊（DungeonsForever）↗：副本、探索與專業手冊。練級路線規劃在專業模組，插件列表要同時啟用 DungeonsForever 和 DungeonsForeverProf。
  • 拍賣小幫手（Auctionator）↗：完整掃描整間拍賣場，把價格提供給無限副本手冊，也接收它匯出的購物清單。
  • 用 CurseForge App 安裝時，遊戲選 World of Warcraft 的永恆（Forever）版本。

照這個順序用

  1. 「設定選項」→「插件」→「Auctionator」→「進階」，在「慢速掃描模式」勾選「預設改成使用另一種速度較慢的掃描模式」。
  2. 到拍賣場，在「拍賣小幫手」分頁按「完整掃描」，等它跑完；慢速模式要比較久。
  3. 「採購與配方」設定裡的「考慮拍賣行的銷售數量」照理能讓路線依掛單件數採購，但 2.1.112 在永恆存下的完整掃描，每樣物品都被判成「不完整」（站主 11/18 的存檔），這個設定目前多半沒有作用。路線用的拍賣價是拍賣小幫手 2 天內最後看到的價格，已經賣掉的便宜掛單可能還在裡面，買之前以拍賣場當下的價格為準。
  4. 輸入 /df 打開無限副本手冊，到專業的練級路線規劃，「路線方案」選「最省錢」，按「自動計算」。路線會用拍賣行價格估成本，並把身上已有的材料算進去。
  5. 按「一鍵導入購物清單」，再到拍賣小幫手「購買」分頁選那份清單，逐項核對價格和數量再買。

站主 2026-11-18 實測可用（無限副本手冊 2.1.112、拍賣小幫手 347）；第 3 步依插件原始碼與站主的存檔判斷，作者修正前先當成提醒。無限副本手冊讀的是遊戲裡拍賣小幫手的資料，掃完不用 /reload；完整掃描超過 2 天，或換角色、換陣營拍賣場之後，要重新完整掃描。插件算出的總價和這頁差很多時，多半是行情變了，以插件當下的計算為準。
