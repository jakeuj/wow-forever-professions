# 軍械庫匯入自動選路

需求類型為新功能。

## 為什麼做

軍械庫已能查到角色的技能、技能上限與已學配方。練等自動選路仍要手動填寫，且採用法術 ID。接上已核對的 Battle.net 配方 ID 對照，讓每位角色可以從自己的專業進度開始試算。

## 要改什麼

- 依正式配方快照和練等配方庫產生雙向唯一的 ID 對照。
- 在軍械庫的製造專業提供匯入，預填目前技能、技能上限與可對應的已學配方，供玩家確認後開始試算。
- 以角色 ID 和專業識別本機計畫。主動重新匯入更新三個官方欄位，保留目標、庫存、角色等級、達標機率及完成勾選。
- 保留既有分享連結及可確認歸屬的舊計畫。

## 影響範圍

配方資料建置、軍械庫角色頁與製造練等表單。原始配方快照留在本機，網站發佈已核對的 ID 對照。
