# 永恆・專業議事廳工具擴充

## 為什麼做

讓玩家從目前的技能、庫存和台區 PvP 部落行情估算練等與採買，再用相同報價找代工、配裝和準備團本。參考 DungeonsForever 的專業流程，玩家開網站即可使用。

## 要改什麼

- 補齊同一輪官方拍賣的價階，提供批量採購、六項製造練等與進度追蹤。
- 提供配方估價、工匠連結與製造利潤篩選。
- 提供台服角色查詢、瀏覽器收藏、多角色專業分工與裝備比較。
- 提供可分享的團本分工備戰清單與採買匯出。

## 影響範圍

GitHub Pages 工具頁面、拍賣排程、公會資料快照及 Cloudflare Workers。維護端使用 DungeonsForever 的已驗證資料，玩家可手動輸入進度及材料。
