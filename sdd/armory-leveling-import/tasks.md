# 工作清單

- [x] 產生雙向唯一的配方 ID 對照，驗證成品及附魔資料。
- [x] 串接軍械庫匯入與練等表單，按角色 ID 和專業保存計畫。
- [x] 驗證重新匯入、舊進度、失敗提示及桌面與手機操作。

## 驗證記錄

- 以正式配方快照建置 1,821 筆對照。玉蛇刀與直接附魔各有一筆核對樣本。
- 本機用 Chromium 以桌面 1440px、手機 390px 驗證軍械庫匯入及實際自動選路。使用模擬角色與行情，測試角色與專業的儲存隔離、重新匯入、舊連結、對照服務失效及儲存受限。
- 38 個 JavaScript 測試與 15 個 Python 測試通過。

## 驗收條件

- 軍械庫已學的玉蛇刀配方 1986 會讓自動選路把法術 3493 視為已學。略過尚無對照的配方時，表單顯示筆數。
- 兩位角色的同一專業，以及一位角色的兩項專業，可各自保存與重開計畫。
- 再次匯入更新技能、上限及已學配方，保留目標、庫存、角色等級、達標機率和完成勾選。
- 對照檔、專業資料或瀏覽器儲存無法使用時保留原計畫。既有分享連結及無角色試算可使用。
