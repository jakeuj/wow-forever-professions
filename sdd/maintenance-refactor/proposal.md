# 練等、行情與維護文件重構

## 為什麼做

把練等資料來源、路線計算與畫面輸出分開，讓改動集中在對應模組。將常用維護入口和依任務查閱的技能文件補齊，縮短新增功能時的查找時間。

## 要改什麼

- 第一批拆出練等產生器的來源讀取、固定路線與估價、目錄與配方對照、HTML 呈現，保留既有指令及輸出。
- 第一批補上 AI 維護入口，並將 Battle.net 實測與本機工具、插件專業衝等操作移至對應參考文件。
- 第二批將行情快照的合併、漲跌與排序移到純函式模組。頁面繼續沿用原有互動與資料格式。

## 影響範圍

練等 Python 工具與測試、README、專案技能的 Markdown 參考、行情頁入口與 Node 測試。每批獨立提交。
