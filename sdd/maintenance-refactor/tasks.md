## 驗收條件

- 固定樣本重建的 HTML、路線目錄、備援價階與配方資料一致。
- 從維護入口可找到新增配方來源、行情排序與軍械庫端點的對應檔案及驗證方式。
- 行情頁沿用收藏分享與購物清單格式，桌機和 360px 預覽皆通過。

## 驗證紀錄

- 相同插件資料和固定行情樣本跑過 10 種 CLI 情境，退出碼、標準輸出及 7 個產物與拆分前一致。
- 從 `AGENTS.md` 可沿 README 找到配方來源及重建指令、行情排序及對應測試，也可沿技能文件找到軍械庫端點規則及實測。
- 固定快照在 1280px 和 360px 比對行情、篩選、收藏分享及購物清單下載，結果一致。Node 42 項及 Python 18 項通過。
