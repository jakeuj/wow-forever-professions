# 專業自動選路與達標機率

需求類型為新功能。

## 為什麼做

現有練等試算用行情和庫存重新估價，從預先整理的路線中挑選方案。材料漲價、缺貨或角色已有其他配方時，玩家需要能從可用配方重新排路線，並知道備妥這批材料後，有多大機率達到目標。

本機 DungeonsForever 2.1.118 的專業模組 2.0.3 已拆出三個可參考的部分。`ProfRouteSolver.lua` 在搜尋狀態記下技能上限、庫存、已處理的配方及已用掉的拍賣件數。`ProfSolverCapture.lua` 定義單次升點模型與按價階購買的增量成本。`ProfRisk.lua` 則逐次製作推進技能機率分布，計入未達學習門檻的機率。本提案以這些行為為參考，在網站實作瀏覽器求解流程。 [DungeonsForever 2.1.118 發布包](https://www.curseforge.com/wow/addons/dungeonsforever/files/9696731)

## 要改什麼

### 玩家輸入與結果

- 在既有六項製造練等頁新增「自動選路」。沿用目前技能、目標技能、已學配方和手動庫存，新增目前技能上限及最低達標機率。達標門檻提供 80%、90%、95%，預設 90%。目前技能上限預設為足以涵蓋目前技能的最低階，玩家已學更高階時可調整。角色等級可選填，用於核對需要等級的學習與升階條件。
- 自動選路以備妥整條路線所需材料、工具、配方與已知學費的新增金幣支出為目標。手邊材料先抵用，費用以銅幣計算。對符合機率門檻且採買可行的方案，先比支出，再比達標機率，最後比製作次數。結果寫明為本次搜尋找到的最低支出。
- 顯示路線區間、配方、預備製作次數、已知支出、材料來源及整條路線的達標機率。輸出沿用現有步驟追蹤與拍賣小幫手匯出。若最好的可執行方案未達門檻，顯示它的達標率並標為未達門檻。若缺料、行情失效或必要前置尚未核實，顯示具體缺口，並提供既有路線試算作為備援。

### 搜尋與成本

- 建置時擴充六項製造的配方目錄，保留已核對的固定路線作為搜尋起點。自動搜尋資料以專業及法術 ID 識別配方，包含可學技能、變色門檻、產量、材料、工具、技能階級及可核實的來源。已學配方直接使用。其他配方的訓練師、配方物品或專精前置，須能由既有資料或玩家輸入確認。
- 每次按下計算時重新取得台區 PvP 部落最新可用的每小時價階，整輪只採用同一份快照。沿用三小時有效期限及同市場完整掃描備援。搜尋狀態逐筆扣除庫存、自製產出與已採買的掛單。一筆需求可混用拍賣價階和已核實供應的 NPC 整包，按整筆追加支出選成本最低的組合。缺價與缺貨分開記錄，整條路線有未計價或未確認支出時列為部分估價。
- 從當前技能搜尋可學或已學的配方組合，按下一個配方門檻、技能上限和目標技能擴展。針對各段保留一批成本較低、達標率較高的候選。只將技能上限、已學配方、庫存、已用價階及機率分布相同的狀態視為同一進度，以較低支出者保留。製作次數與搜尋狀態數都有上限，結果保留預算內找到的最佳可行方案。

### 達標機率與執行方式

- 機率代表按順序使用這份路線預備的材料，達到目標技能的模型估計。沿用插件的單次升點模型及逐次分布更新。每次製作依當前技能把機率分到原技能和升 1 點，低於學習門檻或已變灰時升點機率為 0。橘色為 100%，黃色和綠色依技能位置調整。
- 技能上限只會在路線中達到訓練門檻並完成升階後提高。到某步時尚未滿足學習或升階門檻的機率分支，記為這份路線未能完成。製作中間材料也計入它當次可提供的升點。用完整精度判斷是否達門檻，畫面另外顯示總達標率與最容易卡住的技能門檻。
- 使用 Web Worker 在瀏覽器計算，顯示進度並可取消。每輪搜尋預算先定為五秒，逾時顯示已有結果或暫無可行方案，保留表單與既有路線入口。玩家改用新行情或修改輸入後，上一輪結果不再覆寫畫面。

## 影響範圍

- 擴充 `scripts/build-crafting-leveling.py` 的六製造配方目錄與來源紀錄，維護時使用版本化發布包。
- 在 `crafting-leveling/` 加入搜尋、機率計算及 Worker，並接到既有練等表單、步驟與缺料匯出。
- 沿用 `market/quotes.mjs` 的價階來源及快照有效期。驗證先從鍛造、鍊金術開始，並覆蓋六項製造後開放公開入口。
