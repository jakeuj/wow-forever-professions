# 拍賣行情與配方利潤

依當次行情判斷配方是否值得入手、製造毛利與囤貨條件。本文的案例來自 2026-11 的查證快照。

查現價、漲跌、買賣快訊與購物清單時，讀[拍賣行情](auction-market.md)。算技能區間的材料和採買成本時，讀[專業練等路線](leveling-route.md)。

## 步驟

1. **確認伺服器與陣營。** 阿莫比按 ruleset 分開記價，目前有 `CAMWOW TW4 Realm 2 PvP`（亞服 PvP）、`CAMWOW TW4 Realm 1 PvE`、`CAMWOW US2 Realm 3 PvE`，以 [拍賣場物價](https://wowamobi.com/market) 的伺服器選單為準。提問者沒說時，依上下文推定（例如《黎明之劍》成員是亞服 PvP 部落），並在回覆寫明假設。
2. **跑腳本。**

   ```sh
   python3 '<skill-dir>/scripts/amobi_recipe_value.py' --profession alchemy --faction 部落 --sources
   ```

   `--profession` 用阿莫比的網址代號（alchemy、blacksmithing、enchanting、engineering、leatherworking、tailoring、cooking、first-aid）；附魔的成品是法術，只有配方價、沒有成品價。`--sources` 逐頁讀配方與材料的物品頁，取得分陣營最低價與 NPC 售價；煉金約 100 頁，首次約 3 分鐘，之後 6 小時內用快取（`--max-age` 調整）。`--all` 連本服沒有配方掛單的配方一起列；`--json` 輸出給後續計算。

   查單一物品或更新整頁價格時，見 [阿莫比分陣營價](auction-market.md#阿莫比分陣營價)。

3. **逐列判讀**，先對照 [endgame-crafting.md](endgame-crafting.md) 的 60 級需求與永恆改動（沒涵蓋的專業先上網補查），再依下節規則把每個有掛單的配方歸入一類：**值得買**、**改向 NPC／任務取得**、**先別買**、**觀望**。歸類完成的條件：每項推薦都附上提問者陣營買得到的價格與張數，以及所需技能點。
4. **回報。** 先給分類結論，再註明伺服器／陣營假設、掃描時間，並說明價格是掛單價、不是成交價。

## 判讀規則

- **陣營價**：合併中位數混了聯盟、部落、中立三間拍賣場，便宜的那張常在對面陣營。推薦前看腳本的「{陣營}可買」（自家陣營與中立拍賣場的較低者）。分陣營價後面標了「（M/D 看到）」的，表示最近一次全掃描沒看到這筆，可能已經賣掉。物品頁的分陣營價屬於頁面標題的伺服器，與目標伺服器不同時腳本會略過並註明；只有一間拍賣場有掛單時，頁面不列分陣營區塊，腳本改從標題判斷是哪一方。
- **NPC 與任務優先**：腳本列出 NPC 售價時，AH 價高於 NPC 就改去 NPC 買；限量 NPC 常缺貨，小幅溢價可以接受。任務獎勵的配方也不必花錢，例如次級石盾藥水來自荒蕪之地任務「盧希恩的藥水」。
- **離群掛單**：只有 1～3 張時，中位數常被一張天價或一分錢拉偏（CraftProfit 改用「深度價」，取最便宜 20% 在售件數的平均價來避開，見[插件功能指南](addon-feature-guide.md#13-craftprofit-forever專業視窗內的配方利潤排序)；本 repo 的腳本目前仍用最低價）；要同時看最低價、張數，以及物品頁的每日走勢。近幾天才暴漲的配方先觀望，等價格回落。
- **毛利**：成品價 × 數量 × 0.95（拍賣場抽成）減材料；配方要做幾次才回本＝配方價 ÷ 每次毛利。材料用自家陣營買得到的價格，聯盟草藥常便宜好幾倍（2026-11-18 貓鼬藥劑的材料部落約 2.5g，每瓶只賺約 1.3g）。腳本同時用成品中位數與最低一口價各算一次，並依較低者排序；兩者差很多時以最低價為準，因為中位數可能被一批高價掛單撐高（例：2026-11-17 秘銀盾刺中位數 10 金，部落最低才 1.81 金）。材料按 AH 中位數計；不限量 NPC 的單價較低時改用 NPC，瓶子這類「一次 5 個」的組價，腳本已換算成單價。自己採的草藥仍有機會成本。
- **裝備類成品**：先到成品物品頁看綁定。拾取後綁定（例：黑鐵鎧甲）只有工匠本人能穿，配方價值看工匠的職業與用途。成品寫「需要鍛造（N）」的盾刺、武器鏈等永久附加物品，買家可能也得是鐵匠，轉賣行情要保守估。高階裝備的材料動輒數百金、又沒有成品掛單時，配方的價值在自用或公會開團，不在轉賣。
- **沒有成品掛單**：毛利空白代表沒有價格訊號，不代表不賺。永恆新增的藥劑多屬此類，依效果與團本需求判斷；配方便宜就先買起來卡位。
- **轉化**：有冷卻，毛利指每次冷卻的收益；冷卻長度以遊戲內配方說明為準。
- **礦石與錠**：熔煉一般是一礦一錠，礦石價卻可能高過錠（2026-11-23 部落秘銀礦石 25.74s、秘銀錠 19.99s；真銀礦石 53.99s、真銀錠 23.95s）。這時挖到的礦直接賣，要用錠就直接買錠；自己熔前先比兩邊價格。
- **技能**：配方可以先買，技能點夠了再學；回報時標出「需 N」。

## 配方期貨：囤配方等漲價

問「哪些配方可以先買起來等漲價」時，跨專業跑腳本（加 `--json`），挑出候選後再用 `--sources` 或物品頁看部落價、每日走勢與掉落來源；部落的每小時價格與上架件數看[官方拍賣 API 每小時資料](auction-market.md#官方拍賣-api-每小時資料)，哪個時段比較便宜看[時段與星期的價格](auction-market.md#時段與星期的價格)。經典版的價格史多半只有玩家留言，沒有可靠的長期序列（可信度：攻略與論壇），以下是歸納出的篩選條件：

1. **供給有上限**：只考慮稀有的怪物或首領掉落。商人有賣（含限量商人會補貨）、任務、訓練師、拾取綁定的配方不會漲；很多怪都會掉的配方，價格最後會落到地板價。永恆可能改來源，例：魔暴龍護腿圖樣在經典版是怪物掉落、後來的版本改由 Nergal 販售，永恆攻略寫護腿掉落、手套在 Nergal 賣。
2. **成品要人人反覆消耗**：精煉藥劑、團本藥劑、武器與裝備附魔、人人能穿的裝備。限職業、限專精或限鐵匠使用的成品，買家很少，流動性差。
3. **買在練功潮**：開服後幾個月，練功的人會把撿到的配方低價賣掉；物品頁每日走勢從高點跌到谷底、還有掛單時就是買點。最近一週已經漲了好幾倍的，買點已過。只剩個位數張數的低價可能一夜被掃光重掛（2026-11-17 晚間部落貓鼬藥劑 1.20g・3 張，11/18 變成 28.50g・11 張，聯盟同時 8.34g）：看到買點當下就買，被掃之後不追，手上有的分批賣。同一天也會發生：有限無敵藥水 11/18 上午 0.69g・5 張，下午被掃到 3g・3 張；強效敏捷手套公式那張 55.53g 的重掛消失後，17:06 出現 5g・1 張。所以頁面上每項都寫觸發價（如「10g 以下再買」），每小時資料一到價就提醒站主。
4. **賣在需求事件之前**：團本開放（永恆 2026-12-09）、需要抗性的團本、小號潮；開團當天的買家多半已經買好。經典版十字軍附魔公式開服初期最貴、之後一路下跌，所以「囤越久越漲」並不必然。
5. **每張少量、分批賣**：貴的配方賣得慢，官方也可能熱修來源（經典週年版曾當天修好限量配方被搶的問題、賽季服曾拿掉材料掉落）。
6. **跨陣營價差**：聯盟常比部落貴數倍；中立拍賣場兩邊都能買，可把部落低價買到的配方放到中立拍賣場賣。經典版中立拍賣場抽成 15%（陣營拍賣場 5%），永恆以遊戲內為準。

更新期貨頁的價格與分類：

1. 部落的配方與成品價格、件數用[官方拍賣 API 每小時資料](auction-market.md#官方拍賣-api-每小時資料)；官方資料裡沒有就是現在沒貨。官方資料比最新的完整掃描舊時改用掃描，聯盟與中立用 `amobi_item_prices.py --from-html speculation/index.html`。
2. 逐項對照頁面上的觸發價：到價的往 A 移，低價被掃光、漲回好幾倍的往 C 移，掛單一路變多、價格還在跌的寫「等止跌」。
3. 找新候選時，從官方資料挑出配方類（`market/data.json` 的類別 9）現價不到早上掃描一半的，再查跨陣營價與經典版來源。物品 ID 很大（25 萬以上）的是永恆新增物品，經典版經驗不適用，2026-11-18 看到的兩張（堅韌藥劑、徘徊者皮甲護手）在聯盟都不到 2g；來源說法不一的先不列，例如附魔武器 - 超強衝擊公式，經典版攻略說是黑石塔上層掉落，永恆資料站卻列為購買取得。

不適合囤的典型：秘銀馬刺、秘銀盾刺設計圖。經典版與永恆的成品都標「需要鍛造（215）」才能使用，非鐵匠要把物品放在交易視窗的「不會被交易」欄請鐵匠代裝，所以設計圖的買家幾乎只有接代裝生意的鐵匠；2026-11-17 部落 AH 還有 120 個秘銀馬刺成品、單價不到 1 金，設計圖一週內已經漲了數倍；秘銀盾刺設計圖 11/18 就從 9.50g 跌回 4g，掛單從 8 張變 11 張，中立拍賣場凌晨還有 0.66g。瑟銀盾刺設計圖在經典版非常稀有，是滿級副本坦克的首選盾刺，較有囤的條件。

## 阿莫比資料格式

可信度：本次實測。以下是阿莫比網站自己使用的端點，沒有公開文件。回答玩家問題時低頻讀取並註明來源；公開網站依 [public-data-sources.md](public-data-sources.md) 的規則，只連結頁面。版面改變時，腳本會以「no recipes parsed」或找不到伺服器結束，此時改用瀏覽器閱讀頁面，再修正解析規則。

| 位置 | 內容 |
| --- | --- |
| `/api/market/items` | `groups[]` 每個伺服器一組，`items` 每列為 `[物品 ID, 中位數, 最低一口價, 上架數, 日期, 前次中位數, 前次日期]`，單位是銅；三間拍賣場合成一列：件數加總、最低價取最低、中位數用件數較多的那邊。每組另有 `lastFull`、`lastAny`（Unix 秒）與 `latest`（日期）。`meta[ID]` 第 1 欄是繁中名稱，第 2 欄是品質（0 垃圾、1 普通、2 優秀），第 4 欄是類型（如 `鍊金術`）；名稱可能重複，例如「黑蓮花」有垃圾與草藥兩件，要看品質與類型 |
| `/professions/{代號}` | 伺服器端產生的 HTML，每個 `li.pf-r` 是一筆配方：成品、技能點顏色、學習方式與 `配方：…` 物品、材料 `×N`、效果與「永恆新增」標記 |
| `/items/{ID}` | 每日價格表、「各陣營拍賣場最近看到的最低一口價」（附看到的時間），以及「阿莫比玩家記到的來源」中的商人、限量、組數與售價；最近一次全掃描沒看到時，頁面會註明顯示的是哪次掃描的價格。「經典版參考：怎麼取得」是經典版的掉落資料 |

## 煉金的永恆差異

- 配方名稱與成品不一定相同：「配方：巨人藥劑」做出**強效力量藥劑**（力量 +25）。成品價格以成品 ID 對應。
- 原「配方：強效火力藥劑」（21547）在官方 API 與客戶端資料表已改名為「配方：神聖之力藥劑」，做出**神聖之力藥劑**（神聖傷害 +40），頁面的 `data-ah` 要用新名。阿莫比仍顯示舊名，查價時兩個名稱都可能出現。
- NPC 販售的煉金配方（阿莫比玩家回報，2026-11-17）：

| 點金石、點鐵成金 | 鍊金師匹斯特蘇格（塔納利斯） | 各 80 銀 |
| 超強法力藥水 | 奧格諾恩（幽暗城）、尤希爾（達納蘇斯） | 1 金 20 銀 |
