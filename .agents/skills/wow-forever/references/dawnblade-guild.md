# 《黎明之劍》公會與招募素材

公開內容快照日期：2026-11-11。公會招募頁與 repo 的招生內容是維護依據；後續修改先讀目前內容與本次需求。

## 公開招募資訊與來源

- 公會名稱為 **黎明之劍**，遊戲為《魔獸世界：永恆》，招募標示為 **亞服 PvP／部落**。
- 招募主文：[《黎明之劍》亞服 PVP 招募](https://forum.gamer.com.tw/C.php?bsn=5219&snA=681451)。
- 網站招生區：[永恆・專業議事廳 `#guild`](https://blog.jakeuj.com/wow-forever-professions/#guild)。
- 公開聯絡人、BattleTag 與 Discord 入口統一讀 repo 根目錄的 `index.html`，避免技能另存一份個人聯絡資料。招募聯絡人不代表提問者本人；更新聯絡欄依當次明確指定或已確認的公開來源處理。
- 2026-11-11 的文章寫 **12 月團本開荒**，對應 2026 年 12 月的公會安排；官方團本開放日期須另行查證。跨過該日期後，先核對最新招募內容。
- 文案定位為新手友善、老手帶新手、回鍋與中老年玩家一起復健。保留「老手來當大腿，新手來當潛力股」的口吻，以教學、組隊與長期相處豐富內容。
- 固定團日、出團時段、戰利品分配與職業缺額，依目前公開招募資訊或明確提供的資料處理。

## 文案與插圖

沿用「篝火旁還有位置。」主標，以部落戰友圍坐營火、為新夥伴留下空位的畫面，呼應共同冒險與建立歸屬。公會招募以原創敘述表達開拓、互相扶持與分享經驗的意象。

repo 內可直接使用的素材：

- `assets/guild-campfire-640.webp` 與 `assets/guild-campfire-1280.webp`：響應式營火橫幅，維持完整構圖與前景空位。
- `assets/guild-emblem.webp`：方形劍徽，作為公會識別。
- 文案、聯絡方式與連結位於 `index.html`；核定設計見根目錄的 [公會招生整合計畫](../../../../公會招生整合計畫.md)。

巴哈新增圖片須先完成上傳，再以可用的圖片連結替換草稿連結；輸出格式依當次指定處理。原始圖片、小說全文與私人草稿不屬於公開技能的素材。

## 專業規劃網站中的招生呈現

網站主要入口為 Discord，另提供巴哈全文；打招呼訊息為「網站看到的，想加入黎明之劍」。遊戲內公開聯絡名字保留原有空白，固定團期與職缺由公開招生入口洽詢。

招生區保留靜態 HTML 內容與無 JavaScript 的可讀性；頁內入口保留 `plan／stage／route` 分享參數。網站素材尺寸、介面行為與部署驗證見 [profession-planner-site.md](profession-planner-site.md#公會招生區)。
