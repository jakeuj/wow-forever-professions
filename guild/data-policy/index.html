資料來源與用途

公會概況、工匠名冊與軍械庫使用暴雪 Battle.net API 的《魔獸世界：永恆》台區資料。公會概況顯示角色數、職業與等級統計。工匠名冊顯示遊戲角色名稱、等級、職業、製造專業、技能點數和已學配方。軍械庫按完整角色名稱查詢，也會顯示可查的裝備與天賦。

更新與保存

公會快照每天嘗試更新，自擷取起保留七天。軍械庫按需查詢，快取最多十五分鐘。收藏、個人角色規劃和備戰勾選存在使用者的瀏覽器。實際可代工品項及時間以遊戲內洽詢為準。

撤下角色資料

若想更正或撤下你的角色資料，請透過 黎明之劍 Discord ↗ 私訊公會幹部並提供角色名稱。確認後，管理員會從工匠名冊及軍械庫查詢撤下該角色，並在後續更新中排除。
